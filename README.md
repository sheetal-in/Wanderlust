# Wanderlust

An Airbnb-inspired rental listing platform built using
Node.js, Express.js, MongoDB, Mongoose, and EJS.

## Current Features

- Create and view property listings
- Update existing listings
- Delete listings
- Store listing data in MongoDB
- Render dynamic pages using EJS

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML, CSS, JavaScript

More features and improvements are planned.
